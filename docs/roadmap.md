# Roadmap

The executable task ledger is [`../roadmap.json`](../roadmap.json). Each task has
an owner-independent acceptance criterion, dependencies and an honest status.

The 0.2.0a1 audit implements exact final-sequence primer rematching, multiple
products, state-identity deduplication, full allele evidence and bounded deletion
generation. None of these changes substitutes for independent biological review.

First publish the reviewed independent alpha with passing exact-commit CI. Next
obtain scientific review and a small adjudicated biological benchmark. Use those
cases to choose one read-only caller adapter. Defer empirical dosage models,
broad workflow distribution and native optimization until evidence supports them.

Do not count repository creation, synthetic test coverage or generated marketing
copy as adoption. Repeat use by independent facilities is the adoption gate.
