# Name and positioning

**EditWitness** — know what your CRISPR assay can—and cannot—see.

"Edit" places the package in genome-editing work without committing it to one
nuclease. "Witness" describes its most useful object: a concrete alternative
that demonstrates why a conclusion does not follow from the specified evidence.
It avoids implying that the software guards, certifies or makes an edit safe.

Use `EditWitness` in prose and `editwitness` for the command and Python package.
Avoid an acronym expansion invented solely to fit the name. Lead with the
scientific decision, not with AI, performance superlatives or a claim to replace
trusted callers.

An initial public name search did not identify a dedicated bioinformatics package
with this exact name, but an unrelated software method named `editWitness`
appeared. This is not an exhaustive collision search, trademark clearance, domain
reservation, or confirmation of package-index availability. Check registry
ownership before publication and never assume a matching package belongs to us.
