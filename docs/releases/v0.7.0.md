# DotMatch 0.7.0

This release adds guide-counter-compatible assignment and expands experimental
CRISPRWorks Fit gene-level inference, with reproducible benchmark evidence and
stronger safeguards for scientific output publication.

The recorded synthetic one-mismatch comparison against pinned, unmodified
fulcrumgenomics guide-counter measured 1.6–5.5× faster counting and
11.3–14.4× lower peak memory, with identical counts across all 80 paired
commands. Exact million-read cases favored guide-counter. Measurements apply
to the recorded source and binary hashes; they do not establish biological
accuracy or universal superiority. See the complete benchmark report.

Fit adds joint guide-efficiency/gene-effect inference, whole-gene negative-control
calibration, convergence diagnostics and attainable-FDR diagnostics. Its staged
publication preserves previous output bundles when fitting fails, checks input
hashes, and publishes the completion manifest last. Mid-publication failures
invalidate the completion marker; multi-file crash durability remains a limit.
Malformed MLE counts and duplicate guide IDs are rejected before fitting.

Fit 0.1.0a3 remains an experimental separate package. Independent biological validation,
copy-number confounding and per-gene MLE termination diagnostics remain open.
These changes do not establish general scientific state-of-the-art performance.

First-run tutorials, benchmark graphs, scoped comparison callouts and a
source-linked scientific audit document the supported workflows and limits.

GitHub Release, PyPI and GHCR publication is guarded by exact-commit acceptance
checks, artifact hashes and clean public-install verification. See the release
workflow for the resulting publication evidence. Bioconda and BioContainers
require separately reviewed recipes and public channel propagation; a
version-specific Zenodo archive also requires independent verification.
The separate experimental Fit package is available from this source tree and
its CI build artifacts; it has no configured trusted PyPI publisher.
