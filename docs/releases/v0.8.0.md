# DotMatch 0.8.0

This release makes DotMatch available to coding agents as a local MCP server.

`dotmatch mcp` is a dependency-free stdio MCP server. It exposes
`route_task`, `count_targets`, `demux_barcodes`, `audit_targets` and
`edit_distance` for known-window work, plus the six assay tools, to Claude
Code, Codex, Cursor and other MCP clients. Every tool runs locally, accepts
structured arguments only and refuses to overwrite existing outputs.

```bash
claude mcp add dotmatch -- uvx dotmatch mcp
```

The Claude Code plugin (`/plugin install dotmatch --marketplace dnncha/dotmatch`)
bundles the server with a routing skill.

The release also adds a strict typed Python surface, a scientific reliability
gate with targeted mutation tests, immutable result records and faster Python
bindings. See the CHANGELOG for the full list.

This release is published on PyPI. GHCR, Bioconda and BioContainers still
carry 0.7.0.
