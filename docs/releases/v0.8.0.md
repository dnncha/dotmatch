# DotMatch 0.8.0

DotMatch 0.8.0 protects research files during counting and makes local assay
preparation and review easier to inspect.

Count commands validate requested destinations and stage outputs before
publication. Input/output aliases, duplicate destinations, symlinks, and special
files are refused. Malformed FASTQ and output-write failures preserve previous
results. Successful reruns replace the requested results. Each file replacement
is atomic; the complete set is not crash-atomic. If ordinary publication fails,
DotMatch attempts to restore previous outputs and reports retained backups when
recovery cannot complete.

Python count tables now import as one sample, named `sample`, using `count_total`.
Correction components and QC fields no longer become extra samples. Streamed
assignment writing also preserves previous output when its input iterator fails.

New assay projects have a local `index.html` showing proposed extraction,
orientation, sample mapping, input storage, warnings, and alternative candidates.
Draft projects still require explicit review before counting. Reliability reports
put the recorded verdict and recommended actions first, with responsive tables
and links to available local evidence.

Rebuild the interactive assignment viewer from a completed, checked sensitivity
bundle:

```bash
dotmatch sensitivity-review --bundle sensitivity/ --out review.html
```

The existing renderer verifies the bundle and refuses to overwrite an existing
viewer. No upload or external service is required.

Install the source distribution from this GitHub release with a C compiler and
zlib development headers available. Platform wheels and their checked scope are
listed beside the attached local verification record. PyPI and GHCR remain at
0.7.0 until publication on those separate channels is verified. The previous
immutable 0.7.0 release remains available for rollback.

Matching algorithms, assignment policies, QC thresholds, and biological
validation scope are unchanged. Software checks do not establish biological
accuracy, independent adoption, or clinical suitability.
