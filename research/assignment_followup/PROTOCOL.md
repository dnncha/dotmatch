# Exploratory sequence-level follow-up, declared after the primary results

This is NOT a preregistered validation cohort. It re-examines the SAME six files after primary analysis. The frozen primary same-guide deduplication intervention had exactly zero effect in all six files. A prespecified secondary fixed-window mismatch comparison identified RPL4 and EMG1 as the only two genes meeting the stronger descriptive criterion under both common and policy-specific normalization: >=0.5 gene-level log2 effect change in both technical sets and both ESC libraries, same direction, and >=2 concordantly changed guides per ESC library in pooled data. These two selected genes motivate this post-result sequence inspection.

Question: which observed sequence variants account for mismatch-rescued counts, and what quality evidence accompanies them? Report observed sequences, count per sample/run, mismatch position (1-based), base quality at the mismatch, and frequencies. The matched guide is a computational label; assignment is not proof that the read is a sequencing error or that it came from a functional reference guide.

Select every guide for RPL4 and EMG1 (10 total). Add three distinct control guides per selected guide, chosen with random.Random(20260925) from sorted IDs with pooled fixed-exact plasmid counts between 0.5x and 2x the selected guide and GC difference <=2/19; exclude selected genes, duplicate guides, and reuse of control genes. Selection does not depend on control ESC counts or apparent sequence variants. Preserve the complete selection table.

Use the already validated full-library Hamming nearest-within-one rule at fixed offset23, length19. Re-download identical complete FASTQs or reuse a verified local raw cache. Require original ENA MD5s and read counts. Output every exact and corrected sequence observed for selected guides, with raw Phred+33 mismatch sums, counts at Q>=30 and Q>=40, and window-quality sums. Require exact and corrected counts for every selected guide/run to agree with the first study's count tables.

Interpretation: recurrent high-quality mismatches would make an explanation based only on low-quality base calls insufficient, but would NOT establish true guide mutations, selection for escape, loss of guide activity, independence of molecules, or causality. PCR errors, synthesis/library variants, sample contamination, mapping/reference limitations and systematic sequencing errors remain alternatives. No new essential-gene claim, clinical inference, p-value or new biological cohort is generated.
