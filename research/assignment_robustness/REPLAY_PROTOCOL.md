# Independent remote replay and second-library validation

6 September 2026. This amendment follows the completed local Yusa full-read audit and error-free intervention. It is a reproducibility amendment, not a fresh preregistration of already observed Yusa outcomes. A local execution-service failure occurred after those calculations and after the completed Brunello acquisition. The remaining audit is therefore executed on GitHub's runner; no unavailable local file is silently represented as a newly published artifact.

Known before this replay: full Yusa has 20,394,663 records, 1,428,087 reads with multiple distinct accepted guides, and 1,499,384 excess guide-count events. The local error-free, one-template-per-Yusa-guide experiment yields 94,865 one-mismatch count events from 87,437 reads, and 89,074 exact-mode events. These outcomes are replication targets, not prospective discoveries in this replay. The PHF23 witness was selected after inspecting the Yusa results.

The Brunello read-level multiplicity result has not been inspected. Use the complete already-verified SRR8297997 plasmid archive, corrected library and fixed start 21. This second construct/library is a technical validation set, not a replicated treatment contrast. No gene essentiality, FDR, new biological mechanism or calibrated accuracy claim follows from this audit.

Replay independently with a two-disjoint-seed exhaustive Hamming-radius-one index, verify its candidates against an all-target oracle, and reconcile every guide count with the original pinned native DotMatch output and an actual unchanged guide-counter binary. Validate 200 deterministic randomly selected full-read windows per sample against all reference targets. All record counts, input hashes and full-file archive MD5s must match. Abort on any discrepancy.

Discovery uses only the first 100,000 records per sample. Infer accepted offsets using the original guide-counter event-denominator threshold 0.0025. Infer modal flanks from uniquely exact fixed-window discovery reads; ties are N. Write the complete template model before evaluating later records. This predicts computational multiple-count events among exact-window evaluation reads; it does not identify true biological origin. Retain null findings, excluded evaluation reads and all models.

Repeat balanced, error-free templates for both libraries, and the already-selected PHF23 source-only/depletion/flank intervention for Yusa. Such FASTQs are synthetic controls even though their target reference is real. Use the original actual programs, not their emulations alone. Keep all-target count tables, commands, checksums, source pins and failure artifacts. Commit only aggregate results and reproducible code, not public raw FASTQs. Production code and published releases remain unchanged.

Prior art includes bcSeq (10.1093/bioinformatics/bty402), sequence-context-aware barcode decoding (10.1186/1471-2105-14-272), and crispat (10.1093/bioinformatics/btae535). The candidate contribution is empirical and methodological evidence about read reuse across guide rows and its auditable assay-specific diagnosis, not a claim to have invented mapping uncertainty or context-dependent DNA decoding.
