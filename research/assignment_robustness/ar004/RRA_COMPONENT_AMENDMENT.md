Purpose: isolate the actual RRA component's response to guide dependence without confusing marginal p-value misspecification or unknown biological truth with gene-level aggregation. This is NOT the complete MAGeCK pipeline and must not be labelled as its biological false-discovery rate.

Primary sample ERR376998, comparison SRR8297997. Use their complete verified upstream event classes and per-guide count totals. Exclude zero-total guide rows identically in every arm, before any label draws. In each of 100 repetitions, generate fair record-level coin labels shared across every event of each record. For each guide calculate a randomized exact lower-tail binomial p-value P(K<k)+U*P(K=k), with independent U per guide. Thus every guide has a uniform marginal null p-value conditional on its count, while dependence due to shared records is retained. The counterfactual arm independently splits events for each guide with the identical count totals, so it preserves every guide's marginal binomial null and changes dependence only. This artificial counterfactual is not a different biological sample.

Run the unchanged actual RRA executable with -p 0.1 and --permutation 100 in both arms. Preserve full inputs, gene results, exact commands, binary hash and seeds. The two archives use seeds 20260910 and 20260911. Each arm has its own seeded generator. Under this all-null simulation, any reported discovery is false relative to the artificial label null; this is not an assertion that a biological gene effect is false. Report confidence bounds over independent random label replicates, not over sequencing records treated as biological samples.
